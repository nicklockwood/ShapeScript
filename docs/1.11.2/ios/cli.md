Command Line Tool
---

The `shapescript` command-line tool is available as a separate download for [Mac and Linux](../mac/cli.md). It can check `.shape` files from Terminal, report script errors, and export files without opening a document window, which makes it useful for scripting workflows, bulk export, and automated build pipelines.

On Mac, exporting from the command-line tool requires an unlocked copy of the ShapeScript Mac app to be installed on the same machine. You can still use the command-line tool to check files and report errors without unlocking Export.
